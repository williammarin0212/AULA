# Documentación de la aplicación

## 1. Objetivo
Desarrollar una aplicación que permita utilizar un
modelo de Machine Learning para apoyar la detección
temprana del riesgo de deserción universitaria.

## 2. Herramienta de desarrollo
La aplicación se desarrolla utilizando Streamlit
y Python.

## 3. Funcionamiento
La aplicación tendrá tres etapas:

- Ingreso de información del estudiante.
- Procesamiento de los datos mediante el modelo.
- Presentación del resultado de la predicción.

## 4. Interpretabilidad
Se incorporarán herramientas de interpretación:
SHAP, LIME y gráficos de dependencia parcial (PDP).

## 5. Estado actual
La interfaz inicial está construida.
La conexión con el modelo definitivo está pendiente.

## 6. Alcance
La herramienta tiene fines académicos y de apoyo.
Sus predicciones no deben considerarse decisiones
definitivas sobre la permanencia de un estudiante.
