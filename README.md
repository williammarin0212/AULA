# Predicción del Riesgo de Deserción Universitaria

## Descripción
Aplicación desarrollada para el proyecto integrador de Machine Learning II.
Su objetivo es apoyar la detección temprana del riesgo de deserción
en estudiantes universitarios mediante técnicas de Machine Learning.

## Tecnologías
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- SHAP
- LIME

## Estructura del proyecto
- app.py: aplicación principal.
- requirements.txt: librerías necesarias.
- modelo/: almacenamiento del modelo predictivo.
- datos/: archivos de datos.
- imagenes/: visualizaciones y gráficos.

## Ejecución
Instalar las dependencias:

pip install -r requirements.txt

Ejecutar la aplicación:

python -m streamlit run app.py
